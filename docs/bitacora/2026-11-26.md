## 3. Problemas y soluciones

| Problema | Solución |
|---|---|
| La LCD quedó en pines que ya usaban el buzzer (GPIO17) y el sensor (GPIO23/24) | Se movieron el sensor y el buzzer; la LCD quedó como se cableó |
| `No module named 'luma'` | `pip3 install luma.lcd --break-system-packages` |
| `cannot import name 'bitbang_6800' ... serial` | La clase está en `luma.core.interface.parallel` |
| La tabla `[SCAN]` decía "no llegó ningún paquete" (24 nov) | Se revisó que no hubiera dos programas usando el puerto 5005 (`ps aux \| grep crowdia`) y que la IP no hubiera cambiado. Ahora la LCD muestra `Sin ESP32` en ese caso |

# Bitácora · 22 (noche) y 23 de noviembre de 2026

Inicio del Agente IA 1: grabador de eventos, script de etiquetado y primera recolección de datos.

## 1. Qué se hizo

| Paso | Detalle |
|---|---|
| Grabador de eventos | `crowdia_integrado.py` pasa a **v4**: cada vez que el STA/LTA dispara, guarda la señal cruda (5 s antes hasta 2 s después del final) en `~/crowdia/eventos/` y agrega una fila a `indice.csv`. Con `--etiqueta CLASE` todos los eventos de la sesión quedan marcados con esa clase |
| Etiquetado | Nuevo `etiquetar.py` para poner o corregir etiquetas evento por evento y ver el conteo por clase |
| Recolección | Sesión de 23:39 a 23:55: **15 sacudidas y 20 golpes** (prueba [P14](../04_pruebas_y_resultados.md)) |
| Subida de datos | Desde la Pi con `git push` al fork, usando un token de GitHub con permiso *Contents: Read and write* |

## 2. Resultado

- La regla actual acierta en las dos clases: 15/15 sacudidas con alerta, 20/20 golpes sin alerta.
- Los rasgos de MyShake (IQR, CAV) y el número de picos separan muy bien las dos clases; los cruces
  por cero no.
- Dos eventos de las 23:39 parecen sacudidas mal etiquetadas como `golpe`; hay que confirmarlo.

## 3. Problemas y soluciones

| Problema | Solución |
|---|---|
| `git push` desde la Pi: *Password authentication is not supported* | GitHub ya no acepta contraseña; se usa un token personal (fine-grained) en su lugar |
| `git push`: error 403 | El token solo tenía permiso de lectura; se cambió *Contents* a *Read and write* |

> El token **nunca** se escribe en el código ni en el repositorio.
